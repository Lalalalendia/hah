# RAR Rescue v0.12 — одна кнопка и оригинальная структура

1. Распакуй ZIP, открой `browser://extensions`, включи режим разработчика и нажми «Загрузить распакованное расширение».
2. Обнови страницу Яндекс Диска и открой корень `Диск 2.rar`.
3. Нажми значок расширения, затем единственную кнопку **«Скачать всё»**. Не закрывай вкладку во время прохода.
4. Полученные файлы сохраняются по исходным папкам в `Загрузки/Disk-2.rar/<исходный каталог>/<имя, возвращённое Яндексом>`. Например, клик по `IHE_PDI/10000000/100000` с ответом `100000E1` даст `Загрузки/Disk-2.rar/IHE_PDI/10000000/100000E1`.
5. Не создаются `YandexRARRecovery`, `_unattributed` и другие служебные папки. Если источник не удалось связать с нажатием, файл сохраняется в корне `Загрузки/Disk-2.rar/`, а неопределённость отмечается в журнале.
6. Совпадающие имена не перезаписываются (`uniquify`).
7. После завершения прохода скачивается `Disk-2.rar-download-log.json`: исходные пути, запрошенные имена, имена и размеры полученных файлов, неопределённые соответствия и ошибки.

v0.12 использует новый журнал; записи предыдущего режима без вложенных каталогов не помешают повторному сбору. Наличие файла по ожидаемому пути не доказывает правильность его содержимого: у Яндекса наблюдались ответы с другим именем и с задержкой.
