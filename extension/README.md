# RAR Rescue v0.11 — одна кнопка «Скачать всё»

Экспериментальное расширение Яндекс Браузера для публичного архива
`Диск 2.rar` (https://disk.yandex.ru/d/_RSlWomRWmty1w).

## Установка

1. Распаковать ZIP расширения в отдельную папку.
2. Открыть `browser://extensions` (или `chrome://extensions`),
   включить режим разработчика и нажать «Загрузить распакованное расширение».
3. Выбрать папку с `manifest.json`, обновить вкладку Яндекс Диска.
4. Открыть **корень** `Диск 2.rar` в архивном просмотрщике.
5. Нажать значок RAR Rescue и единственную кнопку **«Скачать всё»**.
   Панель сама найдёт 1286 объектов, если старой карты нет.
6. Оставить вкладку открытой. Кнопка превратится в
   «Остановить после текущего файла». Повторное нажатие после остановки
   возобновляет обход без повторных кликов внутри этого режима.

## Как сохраняются файлы

- **Никаких дополнительных подпапок.** Все вновь полученные файлы
  сохраняются непосредственно в обычной папке загрузок браузера.
- Расширение **не заменяет ответ Яндекса названием запрошенного файла**:
  при запросе `100000`, на который Яндекс прислал `100000E1`,
  сохраняется именно `100000E1`.
- При одинаковых именах используется политика Chrome `uniquify`:
  существующие файлы не перезаписываются, а получают суффикс.
- В конце прохода автоматически создаётся
  `Disk-2.rar-download-log.json`: путь элемента в архиве,
  запрошенное имя, имя браузерной загрузки, байты, фактическое имя
  файла, время, ошибки и признак несовпадения.
- Старый режим мог ошибочно считать успешной загрузку чужого
  содержимого. **Этот режим повторно нажмёт все 1199 исходных
  файловых записей**, даже если старый журнал отмечал их скачанными.
  Повторное нажатие кнопки в рамках v0.11 не повторяет уже
  обработанные позиции.
- Запоздалые загрузки продолжают учитываться до часа после
  завершения прохода. Возможные неоднозначные связи с исходным
  файлом маркируются в JSON как гипотезы, не как проверенный факт.

## Что ещё не подтверждено

Автоматические клики и сканирование архива прошли предыдущие реальные
испытания, но однокнопочная массовая выгрузка v0.11 **ещё не
подтверждена живым прогоном всех 1199 файлов**.

Исходные CRC/SHA отдельных объектов не доступны в нашем журнале:
успешное завершение Chrome ещё не доказывает совпадение содержимого
с исходным архивом. Разбор неверных ответов Яндекса вынесен на потом.

Расширение не запускает скачанные EXE/CMD/SH и не передаёт содержимое
архива, OAuth-токены, cookies либо подписанные URL в GitHub.
