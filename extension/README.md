# RAR Rescue v0.6 — полный каталог + диагностика скачивания

**Цель:** восстановить публичный `Диск 2.rar` с оригинальной структурой
папок, когда сам RAR целиком отвечает HTTP 500, но отдельные элементы иногда
скачиваются через `docviewer.yandex.ru`.

| --- | --- | --- | --- |

Всего в JSON — **88 записей в directories, включая корень**.
Все 1199 файлов пока имеют статус `pending`; это не восстановленный архив.

Подтверждено ручное скачивание `README.TXT` на 2229 байт через просмотрщик.
Однако браузер сохранил этот файл не в нашей папке, а программные клики v0.5

чтобы считать массовое восстановление работающим.

## Установка v0.6

1. **Сохрани** `Disk-2.rar-recovery-report.json` до удаления старого расширения.
   Удаление расширения может удалить его локальное хранилище.
2. В успешном workflow **RAR Rescue Extension Checks** скачай артефакт
   `rar-rescue-v06` и распакуй один раз.
3. В Яндекс Браузере открой `browser://extensions` и загрузи распакованную
   папку с `manifest.json`. Отключи другие экземпляры RAR Rescue.
4. Разреши только текущие домены Яндекса, указанные в `manifest.json`.
5. Открой корень `Диск 2.rar` в просмотрщике. В панели должен быть заголовок
   `RAR Rescue v0.6`.

### Тест без повторного обхода 1286 элементов

1. Нажми **Импортировать карту JSON** и выбери сохранённый
   `Disk-2.rar-recovery-report.json`. При успешном импорте должны появиться
   1199 файлов, 88 каталогов, 1286 объектов и `complete`.
   Если расширение было обновлено на месте и карта уже существует,
   импорт не требуется.
2. Нажми **1. Найти файлы**. Файлов в корне — 8, папок — 7.
3. Нажми **3. Нативный тест README**. **Расширение само ничего не скачивает**,
   оно на 75 секунд вооружает наблюдение за штатной загрузкой браузера.
4. Наведи курсор на `README.TXT` в списке слева и **сам нажми** появившуюся
   кнопку `Скачать` у этого файла (не кнопку всего RAR в шапке).
5. Если браузер начал скачивание, расширение должно изменить путь на
   `Загрузки/YandexRARRecovery/Disk-2.rar/README.TXT` и записать ненулевой
   результат в локальный журнал. Если этого не произошло, нажми
   **Скопировать диагностику** и передай только JSON. Он содержит имена
   файлов, статусы, тип `blob/https`, источник и результаты, но **не содержит**
   подписанных URL, cookies, токенов или HTML.
6. **Проверить автоматический клик** — отдельный тест синтетического нажатия,
   максимум одна попытка. Не запускай его одновременно с нативным.
   `lastAutoCommand.userActivationAtClick` покажет, было ли у кода
   пользовательское разрешение на действие.

**Не нажимай «Скачать всё со структурой» до подтверждения, что
АВТОМАТИЧЕСКОЕ скачивание хотя бы одного файла реально работает.**
Нативный тест проверяет перехват и каталог, но не доказывает способность
скачать 1199 файлов без ручных кликов. Поэтому нативный успех не снимает
этот защитный барьер.

## Проверка безопасности импорта

Модуль `manifest-model.js` заново вычисляет все относительные пути и
проверяет 1286 объектов, 88 каталогов (включая корень), 1199 файлов,
единственность Windows-имён, связь родителей и содержимого. Импорт
**не принимает на веру** скачанные статусы: все записи переводятся в
`pending`, их нужно сверять с загрузками. Отчёт не загружается в GitHub.

## Дальнейшие этапы

После нативного теста и сопоставления `chrome.downloads`:

- Если реальный клик работает, а синтетический нет — выяснить механизм
  загрузки отдельных элементов в браузере. Не запускать 1199 слепых кликов.
- Если автозагрузка заработает — последовательный проход 1199 элементов
  по сохранённой карте, ограниченные повторные попытки, отказ от
  перезаписывания и отчёт о недоступных файлах.
- Сверить CRC/размеры с метаданными, если они доступны у Яндекса. Один
  `chrome.downloads.state="complete"` ещё не доказывает целостность.
- При необходимости создать отсутствующие пустые папки и перепаковать
  извлечённые файлы. SHA-256 нового архива не обязан совпасть с оригиналом.

## Ограничения доступа

Используются только `downloads`, `storage` и доступ к узким доменам Яндекса.
Более мощный `debugger`, который даёт доступ ко всем веб-страницам, не
запрашивается. EXE/CMD/SH из архива не запускаются. Не сохраняй в репозитории
данные авторизованной сессии.
